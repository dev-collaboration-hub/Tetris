# Lightweight Tetris Game 🧱

A lightweight Tetris game built from scratch with a focus on clean architecture, smooth gameplay, performance, and core game development fundamentals.

## 🎯 Project Goal

The goal of this project is to create a simple, efficient, and well-structured Tetris implementation while understanding the internal systems behind puzzle-based games.

## ✨ Features

* Classic Tetris gameplay
* Falling block mechanics
* Tetromino movement
* Block rotation system
* Line clearing logic
* Score tracking
* Level progression
* Game over handling

## 🏗️ Architecture

The project focuses on separating important game systems:

* Game Loop
* Input System
* Rendering System
* Tetromino System
* Grid Management
* Collision Detection
* Score System
* State Management
